MYTRIA02 — Plano Mestre do Projeto

Objetivo

Construir o MYTRIA02 com interface profissional, jogos, missões, máquinas virtuais de mineração, economia controlada e armazenamento seguro dos dados.

Regras de desenvolvimento

- Desenvolver por etapas e testar cada funcionalidade.
- Não marcar tarefas como concluídas sem verificação.
- Nunca colocar senhas ou tokens no código.
- Usar Firebase Authentication para identificar usuários.
- Usar o UID autenticado como identificador do documento do usuário.
- Proteger os dados com regras do Firestore.
- Não confiar no cliente para definir saldos, recompensas ou poder de mineração.
- Manter o código organizado e versionado no GitHub.
